# Changelog

All notable changes to this project are documented here. Generated from Conventional Commits; breaking changes get their own section with upgrade steps.

## Unreleased

### Added

- Monorepo with the web workspace, strict TypeScript, ESLint, Prettier and git hooks
- Workspace JSON Schema v1 (`schemaVersion: 1`)
- Domain core: ULID ids, hybrid logical clock, per-field merge with element sets, fractional ordering keys, schema migrations framework, accessible pastel palette
- IndexedDB storage adapter with a storage contract suite
- Responsive app shell (phone bottom navigation, tablet drawer, desktop sidebar), light/dark/system theme, installable offline PWA
- Unit, component and WebdriverIO end-to-end test harness
