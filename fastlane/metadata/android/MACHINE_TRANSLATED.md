# Machine translated listings

The store listings in these folders are machine translated from `en-US/` and **not checked by a
person yet**:

- `de-DE/` (German)
- `es-ES/` (Spanish)
- `fr-FR/` (French)

If you speak one of these languages, corrections are welcome. Once someone has read a language,
remove it from this list. `brand/store/README.md` has the rest of the listing's notes.
